SCENE BOX PWA 설치 안내

1. 이 폴더의 파일을 HTTPS 웹사이트에 함께 올립니다.
2. 안드로이드 Chrome에서 index.html 주소를 엽니다.
3. 화면의 “앱 설치” 버튼 또는 Chrome 메뉴의 “앱 설치/홈 화면에 추가”를 누릅니다.

주의
- index.html 파일을 단독으로 열면 사진 정리는 가능하지만 PWA 설치와 오프라인 캐시는 작동하지 않을 수 있습니다.
- 사진과 분류 정보는 해당 브라우저/앱의 내부 저장소에 보관됩니다.
- 앱 삭제, 브라우저 데이터 삭제, 휴대폰 초기화 전에 반드시 “전체 백업”을 저장하세요.
- 백업 JSON 파일에는 사진 원본이 포함되므로 파일 크기가 클 수 있습니다.
